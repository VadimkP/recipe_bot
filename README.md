# 🍽 Recipe Bot — Telegram-бот для рецептов и продуктовой корзины

Бот хранит рецепты в SQLite и помогает составлять продуктовую корзину по категориям.

---

## 📋 Возможности

| Команда   | Описание                                                    |
|-----------|-------------------------------------------------------------|
| `/start`  | Приветствие и список команд                                 |
| `/add`    | Добавить новое блюдо (название → ингредиенты → рецепт)     |
| `/list`   | Показать все сохранённые блюда                              |
| `/recipe` | Получить полный рецепт выбранного блюда                    |
| `/cart`   | Составить продуктовую корзину из нескольких блюд           |
| `/delete` | Удалить блюдо из базы                                       |
| `/cancel` | Отменить текущий диалог                                     |

---

## 🚀 Быстрый старт

### 1. Получи токен бота

1. Напиши [@BotFather](https://t.me/BotFather) в Telegram
2. Создай нового бота командой `/newbot`
3. Скопируй полученный токен

### 2. Настрой окружение

```bash
# Клонируй или скачай проект
cd recipe_bot

# Создай файл .env из шаблона
cp .env.example .env

# Вставь свой токен в .env
nano .env   # или любой редактор
```

Содержимое `.env`:
```
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 3. Запусти через Docker Compose

```bash
docker compose up -d --build
```

Бот запустится в фоне. Проверить логи:
```bash
docker compose logs -f
```

Остановить:
```bash
docker compose down
```

## 🥩 Категории продуктов

Ингредиенты автоматически сортируются по категориям:

- 🥩 **Мясо / Рыба** — говядина, курица, лосось, ...
- 🥛 **Молочные продукты** — молоко, сыр, сметана, ...
- 🌾 **Крупы / Мука / Бобовые** — рис, гречка, макароны, ...
- 🥚 **Яйца**
- 🥦 **Овощи / Фрукты / Зелень**
- 📦 **Прочее** — всё остальное

## 💾 База данных

SQLite-файл хранится в Docker Volume `bot_data` → `/data/recipes.db`.  
Данные сохраняются между перезапусками контейнера.

Чтобы сделать бэкап:
```bash
docker cp recipe_bot:/data/recipes.db ./backup_recipes.db
```

cd bot
